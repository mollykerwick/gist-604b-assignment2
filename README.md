# gist-604b-assignment2

GIST 604B Assignment 2: QGIS Desktop GIS Projects

## Overview

- This repository is a demonstration of 10 example guides from the QGIStutorials.com. The projects folder includes the .qgz project files created during the tutorials. The outputs folder includes the screenshots of the map canvas and layers panel for each tutorial in .png format. The names of the .qgz and .png files include the name of the tutorial followed by my last name, Kerwick.
- The GIS skills practiced during these QGIS tutorials include loading .shp files, loading tabulated data, creating layers, utilizing the processing toolbox, defining geographic CRS, projecting layers for analysis, and much more.

- QGIS 3.44 Solothurn
- Windows 11

## Reflection

As I completed these tutorials, the function of using a desktop GIS software became clearer. As a data science student with a background in mainly Python and R for GIS mapping, the built-in functionality and readability of QGIS made learning new types of analysis very fast and intuitive. During the heatmap creation tutorial, I started to better understand the need for projected CRS for analyzing distance measurements, and the difference between projected CRS and geographic CRS. I found the use of the processing toolbox very effective for geospatial computations. The most challenging part to me was being overwhelmed with options. While the tutorials are an effective resource for similar projects, I am unsure of all of the functionality of QGIS making it difficult to imagine new research questions and applications. With more practice with QGIS I will start to better learn what questions I can answer with it. I hope to use these skills to perform complex geospatial analysis more quickly than I normally do in Python for environmental applications including oceanography, seismology, and atmospheric science.
